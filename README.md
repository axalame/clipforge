# Video Studio Pro 🎬

Современная профессиональная десктопная студия для видеообработки, монтажа и скачивания потокового видео с веб-сервисов.
Построена на базе **Rust (Tao + Wry + Tiny-HTTP)** и **Vue 3.5 (TypeScript, Vite, Pinia, Naive UI, Vue-i18n)**.

---

## ✨ Основные возможности (Features)

* 📥 **Умный загрузчик видео:**
  * Автоматическое определение сервиса (YouTube, Twitch, Rutube, VK Видео, TikTok, Vimeo, X/Twitter, Instagram, Bilibili и др.).
  * Выбор видео- и аудио-потоков, форматов (MP4, MKV, WebM), скачивание фрагментов по таймкодам.
  * Поддержка авторизации через `cookies.txt` или прямо из браузера (Firefox, Chrome, Edge).
  * Пакетный режим загрузки сотен ссылок.
* ✂️ **Монтаж и нарезка (Trim & Cut):**
  * Точная покадровая обрезка видео без перекодирования (0% CPU, мгновенная скорость).
  * Изменение скорости и темпа видео с сохранением тональности звука.
  * Пакетная и последовательная склейка файлов очереди.
* 📐 **Кадрирование и трансформация кадра (Geometry):**
  * Интерактивный интерактивный холст (Crop Box) с пресетами (16:9, 9:16, 1:1, 4:5, 21:9).
  * Изменение разрешения (Resize), поворот и отражение кадра, смена частоты кадров (FPS).
* 🎨 **Эффекты, текст и наложения (Effects):**
  * Наложение водяных знаков (изображений) с регулировкой прозрачности, размера и позиции.
  * Текстовые оверлеи с выбором шрифта, цвета, размера и подложки.
  * Наложение динамического таймкода и даты/времени.
  * Зоны цензуры и размытия (Blur), режим «Картинка в картинке» (PIP).
* 🔊 **Обработка звука (Audio):**
  * Нормализация громкости по стандарту EBU R128 (-14, -16, -23 LUFS).
  * Удаление пауз и тишины (Silenceremove), удаление/замена звуковой дорожки.
* 📦 **Экспорт и сжатие (Export):**
  * Сжатие через кодеки H.264, H.265 (HEVC), VP9, AV1 с управлением CRF/битрейтом.
  * Конвертация видео в анимированный GIF.
* 📁 **Медиатека и плеер (Media):**
  * Встроенный потоковый плеер с поддержкой HTTP 206 Partial Content (плавная перемотка).
  * Просмотр технических спецификаций медиапотоков (ffprobe).

## 🏛️ Архитектура проекта

```
video-studio-pro/
├── Cargo.toml                    # Конфигурация Rust и зависимости (Wry, Tao, RustEmbed, Tokio)
├── build.rs                      # Сборщик и встраивание ресурсов Windows
├── src/                          # Нативный Rust бэкенд
│   ├── main.rs                   # Tao EventLoop, системный трей, WebView2 IPC
│   ├── api.rs                    # Безопасный типизированный RPC диспетчер
│   ├── media_server.rs           # Локальный HTTP сервер с песочницей и rust-embed
│   ├── ffmpeg_builder.rs         # Безопасный построитель команд FFmpeg
│   ├── ytdlp_runner.rs           # Загрузчик yt-dlp с потоковым парсингом и санитизацией
│   ├── process_runner.rs         # Управление дочерними процессами с изоляцией JobObject
│   ├── media_info.rs             # Быстрое извлечение технических метаданных (ffprobe)
│   └── config.rs                 # Автоопределение путей системных утилит
└── frontend/                     # Модульный фронтенд (Vue 3 + Vite)
    ├── package.json              # Vue 3.5, Naive UI, Pinia, Vue-i18n
    ├── vite.config.ts            # Сборка SPA в dist
    ├── tsconfig.json             # Строгий TypeScript
    └── src/
        ├── App.vue               # Корневой шелл: Topbar, Sidebar, Drawer терминала
        ├── main.ts               # Точка входа Vue приложения
        ├── api/client.ts         # Типизированный клиент вызовов IPC
        ├── types/index.ts        # Строгие типы данных
        ├── stores/               # Pinia сторы (app, queue, task, config)
        ├── styles/main.css       # Тематические переменные (Dark/Light)
        ├── components/layout/    # Topbar, Sidebar с SVG иконками
        ├── views/                # Модульные экраны (8 разделов студии)
        └── locales/              # Полная локализация: ru-RU и en-US
```

## 📦 Установка и запуск

### Вариант 1. Готовые сборки (Releases)
Перейдите на страницу **[Releases](../../releases)** этого репозитория:
* **`video-studio-pro-setup.exe` (Классический установщик Windows):**
  * Позволяет выбрать папку установки (по умолчанию `Program Files`).
  * Создаёт ярлык на рабочем столе и в меню «Пуск».
  * Добавляет программу в системный список «Установка и удаление программ» с возможностью чистого удаления.
* **`video-studio-pro-portable.zip` (Портативная версия):**
  * Достаточно распаковать в любую папку и запустить `video_studio.exe`.
  * Приложение автономно — весь фронтенд, стили и сервер встроены внутрь бинарного файла через `rust-embed`. Дополнительные серверы или рантаймы запускать не требуется.

### Вариант 2. Сборка из исходников

#### Требования:
* **Rust**: `1.75+` (stable)
* **Node.js**: `20+` и `npm`
* Установленный **WebView2 Runtime** (входит в состав Windows 10/11 по умолчанию).

#### Инструкция по сборке:
```bash
# 1. Сборка интерфейса (Vue 3 SPA)
cd frontend
npm install
npm run build
cd ..

# 2. Запуск тестов бэкенда
cargo test

# 3. Компиляция оптимизированного релиза
cargo build --release

# Готовый бинарник будет доступен по пути:
# target/release/video_studio.exe
```

## ⚙️ Внешние утилиты (FFmpeg & yt-dlp)
Для полноценной работы монтажа и скачивания видео приложению требуются:
* **FFmpeg** (`ffmpeg.exe`, `ffprobe.exe`)
* **yt-dlp** (`yt-dlp.exe`)
* *(Опционально)* **Deno** (`deno.exe`) для работы современных экстракторов YouTube.

> **Умное автоопределение:** Студия автоматически ищет установленные утилиты в стандартных путях, в системном `PATH`, а также в каталоге `com.imsyy.yt-dlp-gui`. Если утилиты установлены в нестандартную папку, их пути можно в 1 клик указать в разделе **Настройки**.
