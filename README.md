# ClipForge

Быстрая десктопная студия для обработки, монтажа и скачивания видео.
Построена на базе **Rust** (Tao, Wry, Tiny-HTTP) и **Vue 3** (TypeScript, Vite, Pinia, Naive UI).

---

## Возможности

- **Загрузка видео (yt-dlp):**
  - Поддержка YouTube, Twitch, Rutube, VK Видео, TikTok и других сервисов.
  - Выбор потоков, встраивание и скачивание субтитров (.srt), нарезка по главам.
  - Авторизация через `cookies.txt` или браузер (Chrome, Firefox, Edge).
  - Пакетная загрузка очереди ссылок.

- **Монтаж и нарезка:**
  - Покадровая обрезка без перекодирования (прямой стрим без нагрузки на CPU).
  - Изменение скорости и темпа с сохранением тональности звука.
  - Склейка фрагментов очереди.

- **Геометрия и Shorts:**
  - Интерактивный кроп с пресетами (16:9, 9:16, 1:1, 4:5, 21:9).
  - Адаптер **9:16 Shorts / Reels** с размытым фоном (Smart-Blur).
  - Изменение разрешения, поворот, отражение и изменение FPS.

- **Эффекты и наложения:**
  - Водяные знаки, текст (с поддержкой кириллицы), таймкоды, размытие и цензура (Blur / PIP).

- **Обработка звука:**
  - Извлечение аудиодорожки из видео в **MP3** (с битрейтом 128, 192, 256, 320 kbps), несжатый студийный **WAV** (16-bit PCM) или прямое копирование потока (**Copy**) без перекодирования.
  - Мгновенное удаление звука из видео (**Mute**) без потери качества видеоряда (direct stream copy).
  - Нормализация громкости по стандарту EBU R128 (-14, -16, -23 LUFS).
  - Умное удаление пауз и тишины (с настройкой порога dB и минимальной длительности).
  - Замена аудиодорожки на новый аудиофайл (MP3, WAV, AAC, FLAC).

- **Управление компонентами:**
  - Встроенный загрузчик внешних зависимостей (FFmpeg, FFprobe, yt-dlp, Deno) с прогресс-баром и авто-распаковкой.

- **Экспорт и сжатие:**
  - Режим **Fit-to-Size**: точный расчет битрейта под размер (10 МБ, 25 МБ Discord, 50 МБ Telegram, 100 МБ или свой размер).
  - Экспорт в анимированный **WebP** и GIF.
  - Кодеки H.264, H.265 (HEVC), VP9, AV1 с контролем CRF и битрейта.

## Установка

### Готовый инсталлятор
Скачайте **`clipforge-setup.exe`** со страницы [Releases](../../releases). Установщик настроит ярлыки и регистрацию в системе.

### Сборка из исходников
Требуются **Rust 1.75+**, **Node.js 20+** и Windows WebView2:

```bash
# 1. Сборка фронтенда
cd frontend
npm install && npm run build
cd ..

# 2. Сборка релизного бинарника
cargo build --release
```
Исполняемый файл: `target/release/clipforge.exe`.

## Требования

Для работы функций монтажа и скачивания требуются:
- **FFmpeg** (`ffmpeg.exe`, `ffprobe.exe`)
- **yt-dlp** (`yt-dlp.exe`)
- *(Опционально)* **Deno** (`deno.exe`) для экстракторов YouTube.

Пути определяются автоматически или настраиваются в интерфейсе в разделе **Настройки**.
