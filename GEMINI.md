# 🛡️ ПРАВИЛА ПРОЕКТА VIDEO-STUDIO-PRO (CLIPFORGE)

## 1. СТРОГИЙ ЗАПРЕТ АВТО-ДЕПЛОЯ (DEPLOY & RELEASE POLICY)
- **ДЕПЛОЙ / ОТПРАВКА НА GITHUB ТОЛЬКО ПО ЯВНОМУ УТВЕРЖДЕНИЮ:**
  Никаких `git push`, создания тегов на GitHub, запуска релизных пайплайнов без ПРЯМОГО указания пользователя (например: «залей», «отправь на гитхаб», «деплой»).
- Любые изменения сначала проверяются и тестируются ЛОКАЛЬНО:
  1) `npm run build`
  2) `cargo build` / `cargo test`
  3) Запуск и тестирование приложения пользователем на локальной машине.
- Только после явного подтверждения пользователя («отправляй / деплой / залей») выполняется отправка на GitHub.

## 2. БЕЗОПАСНОСТЬ (SECURITY)
- Ноль секретов, паролей, токенов в исходном коде и коммитах.
- Все ключи и токены — исключительно через `.env` (который строго в `.gitignore`).
- Пре-коммит аудит: проверка `git diff --cached` перед каждым коммитом.
